# AI Project 2 – Data Classification Using AI

## Overview
This project is a simple Machine Learning application with a Tkinter GUI that classifies Iris flower species using the K-Nearest Neighbors (KNN) algorithm.

### Features
- Iris dataset classification
- Feature scaling using StandardScaler
- Train-test split
- KNN classifier
- Accuracy Score
- F1 Score
- Confusion Matrix
- Tkinter GUI

## Technologies Used
- Python
- Tkinter
- Scikit-Learn
- Matplotlib

## Installation

```bash
pip install scikit-learn matplotlib
```

## Workflow

1. Load Iris Dataset
2. Apply Feature Scaling
3. Split Data into Training and Testing Sets
4. Train KNN Model
5. Make Predictions
6. Evaluate Model

## Evaluation Metrics

- Accuracy Score
- F1 Score
- Confusion Matrix
